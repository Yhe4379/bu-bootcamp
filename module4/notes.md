# Module 4 Notes: Git and GitHub Workflow

In this module I learned how to:
- Initialize and clone a Git repository
- Stage changes with git add and save them with git commit
- Push local commits to GitHub with git push
- Create a branch to work on changes in isolation
- Open a pull request and merge it back into main

Key idea: commits belong to a branch, not the whole repository.
Switching branches changes what my working directory shows.
